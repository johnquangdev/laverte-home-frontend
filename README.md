# laverte-web

Giao diện website ý tưởng cho **La Verte**, lấy cảm hứng từ ngôn ngữ thị giác đã crawl từ Modern Village Lifestyle và định vị thật của mô hình trong workspace thương hiệu:

- phần mở đầu dùng ảnh thật, nội dung overlay và định vị lưu trú riêng tư theo giờ
- header trong suốt chuyển sang nền trắng khi cuộn
- tương phản đen/trắng với màu nhấn cam
- tiêu đề serif giàu cảm xúc kết hợp Be Vietnam Pro
- khu vực triển khai, gói trải nghiệm theo block giờ, chuẩn vận hành và chân trang nền đen

## Chạy trên máy

```bash
npm run dev
```

Sau đó mở:

```text
http://localhost:5179
```
